# M365-Security-Lab
# Project Overview

This project demonstrates the implementation of Microsoft 365 security controls including Microsoft Entra ID, Multi-Factor Authentication (MFA), Conditional Access, Microsoft Defender, and Microsoft Purview. The objective was to improve identity security, strengthen access controls, and monitor security events within a Microsoft 365 tenant.
